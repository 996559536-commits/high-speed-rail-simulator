# 高铁模拟器

由 Sites 官方源码仓库导出的独立副本。保留原 Sites 项目，此副本不配置自动部署。

## 本地预览

需要 Python 3，在仓库目录运行：

```sh
python3 -m http.server 8000 --directory dist
```

随后访问 http://localhost:8000 。

## 文件与限制

`dist/` 为可编辑发布代码，主游戏代码有内联打包；尚未恢复独立原始开发模块或测试。无需 npm 安装、付费 API Key 或服务器资源。
